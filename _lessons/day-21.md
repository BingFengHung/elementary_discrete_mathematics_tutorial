> 準備：紙、筆、名字卡、幾顆積木。可以邀請家人一起試玩。

## 最後的任務：換你出題

二十天前，偵探社還在為玩具怎麼分而煩惱。現在你會整理條件、數可能、讀地圖，還能檢查理由。

今天你不只當解題者，也當設計者。我們先完成一個能直接試玩的範例，再把它改成自己的版本。

遊戲叫作「森林寶箱任務」。玩家要先選隊員，再決定裝備，最後走到寶箱。三關都能說明理由，就算成功。可以回頭修改答案，不需要比誰最快。

隊員資料如下，這一輪不交換物品：

| 隊員 | 有地圖 | 有鉛筆 | 有帽子 |
|---|---|---|---|
| 小安 | 是 | 是 | 否 |
| 小米 | 否 | 是 | 是 |
| 阿樂 | 是 | 否 | 是 |
| 小晴 | 是 | 是 | 是 |

加入條件是「有地圖，而且有鉛筆」。請選出所有符合者。

小安和小晴都符合。小米只有鉛筆，阿樂只有地圖，兩人都少一項。帽子在這一關不是條件，不能因為小晴有帽子就只選她，也不能因為小安沒有帽子就排除他。

你可以畫兩個重疊圈圈，將隊員放好，再讀出交集。這是在使用集合與邏輯。

## 第二關：裝備有幾種搭配？

背包有紅、藍兩色，徽章有星星、月亮、雲朵三款。每次選一個背包與一款徽章，但紅背包不能配月亮徽章。

沒有任何限制時，有 2×3＝6 種。劃掉紅背包配月亮那一種，剩五種：紅星、紅雲、藍星、藍月、藍雲。

也能畫樹狀圖：紅色分出星星、雲朵兩枝；藍色分出星星、月亮、雲朵三枝。末端共五個。

同一個問題用表格與樹狀圖都得到五種，可以互相檢查。只報數字還不夠，請至少展示一種整理方式。

## 第三關：找出步數最少的路

畫出 A 入口、B 樹屋、C 池塘、D 涼亭、E 寶箱五個點，只連下列道路，全部可以雙向通行：

| 道路 | 步數 |
|---|---|
| A—B | 2 |
| B—E | 7 |
| A—C | 3 |
| C—D | 2 |
| D—E | 2 |

A—B—E 共 2＋7＝9 步；A—C—D—E 共 3＋2＋2＝7 步，所以後者較短。

不能看到第一步 A—B 只有兩步，就認定整條最好。所有邊的步數都大於零，繞圈只會增加步數；在這張小圖上，不重複地點的兩條候選路線都比較過了。

請玩家寫出沿路的地點與加法算式，讓別人能確認他的路是真的存在，也沒有把數字加錯。

## 加分關：用一句話說明一定會發生的事

假設有四位玩家，每人選星星、月亮、雲朵其中一款徽章。一定有人同款嗎？

有。四個人分到三種徽章，如果每款最多一人，只能容納三人，所以至少某款被兩人或更多人選到。

我們不知道是哪款，也不保證每款都有人選。說明結論時，不要比理由能保證的範圍更大。

## 動手玩：現在換你設計

先決定主題，可以是海底、太空、校園或動物村。再完成以下作品：

1. 一張資料表：四到六個角色，每個角色有清楚的條件。
2. 一個計數關卡：定義怎樣算不同結果，至少加入一項需要注意的限制。
3. 一張路線圖：說明線能否雙向走、數字代表什麼、起點和終點在哪裡。
4. 一份解答：每關除了答案，至少寫一句理由。

第一次先用小數量。四個角色、五個地點就能設計有趣的關卡，資料多不代表一定更好玩。

## 試玩是設計的一部分

把作品交給家人，先讓他只看紙上的說明，不要在旁邊偷偷補規則。記下他停在哪裡、問了什麼、是否找出另一個合理答案。

如果同時有兩條最短路，可以接受兩個答案，並把說明寫成「找出一條最短路」或「找出所有最短路」，不必假裝只有你原先想到的那條才對。

若題目讓人誤會，就修改文字或地圖，再試一次。修正規則不是失敗，而是在讓遊戲更清楚。

## 三道小挑戰

1. 範例中能加入探險隊的有誰？
2. 如果取消紅背包不能配月亮的限制，裝備搭配會增加幾種？總共幾種？
3. 有人找到與標準答案不同、但同樣符合規則的解法，你應該先做什麼？

## 把二十一天的方法帶走

你現在有五個可以反覆使用的問題：「條件說清楚了嗎？」「什麼算不同？」「有沒有漏掉或重複？」「每一步能照做嗎？」「為什麼這個理由成立？」

**離散數學的學習可以繼續，而你已經能用清楚的規則和理由，設計自己的小小數學世界。**
