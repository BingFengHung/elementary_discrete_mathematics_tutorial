> 今天的任務：分清楚「而且」「或者」「不是」，讀懂闖關條件。
>
> 準備：紙、筆、四張角色卡。

## 門上的一個詞，決定誰能進去

偵探社開了兩個練習室。第一間的門牌寫著：「帶鉛筆，而且帶橡皮擦，才能進入。」第二間寫著：「帶鉛筆，或者帶橡皮擦，就能進入。」

小安兩樣都帶了，小米只有鉛筆，阿樂只有橡皮擦，小禾兩樣都沒帶。

「只有一個詞不一樣，規則應該差不多吧？」小米問。

先替四位同學猜一猜：誰能進第一間？誰能進第二間？我們今天假設門牌寫的就是完整條件，沒有其他進入限制。

## 而且：兩邊都要成立

第一間需要鉛筆，也需要橡皮擦。只帶一樣還不夠，所以只有小安能進入。

你可以伸出左右兩隻手：左手代表「有鉛筆」，右手代表「有橡皮擦」。有就舉起來，沒有就放下。使用「而且」時，要兩隻手都舉起來才通過。

| 角色 | 有鉛筆 | 有橡皮擦 | 兩樣都有嗎？ |
|---|---|---|---|
| 小安 | 是 | 是 | 是 |
| 小米 | 是 | 否 | 否 |
| 阿樂 | 否 | 是 | 否 |
| 小禾 | 否 | 否 | 否 |

這和 Day 2 的交集有關：同時在「帶鉛筆」和「帶橡皮擦」兩個集合裡的人，才符合條件。

第二間只要有其中一樣就能進。因此，小米和阿樂都能進，小禾不能進。

那小安呢？他兩樣都帶，會不會反而不符合？

在數學中，「或者」通常表示**至少一個條件成立，也允許兩個都成立**。因此小安也能進。用剛才的手勢，只要至少一隻手舉起，就通過。

| 有鉛筆 | 有橡皮擦 | 而且 | 或者 |
|---|---|---|---|
| 是 | 是 | 通過 | 通過 |
| 是 | 否 | 不通過 | 通過 |
| 否 | 是 | 不通過 | 通過 |
| 否 | 否 | 不通過 | 不通過 |

你不必背整張表。想成「兩樣都要」和「至少一樣」，就能自己重新判斷。

## 生活中的「或」有時需要問清楚

買套餐時，店員可能說：「附餐選薯條或沙拉。」店裡通常只讓你選一份，不一定允許兩份都拿。這是情境另外提供的限制。

為了寫出清楚的遊戲規則，可以直接說：「兩種中恰好選一種，不能都選。」不要讓讀者猜。

今天的數學練習若只寫「或者」，就採用允許兩者都成立的意思。先約定詞語怎麼用，大家才不會各自照不同規則作答。

## 不是：把原本的真假翻過來

「小安帶了鉛筆」是真的，所以「小安沒有帶鉛筆」就是假的。

但如果原句比較長，就要小心。「不是兩樣都帶」，意思是沒有同時帶齊兩樣。只有鉛筆、只有橡皮擦、兩樣都沒有，都符合。

它不等於「兩樣都沒帶」。第一個說法允許帶一樣，第二個說法連一樣也不能有。

你可以用小米當例子：她只帶鉛筆，確實不是兩樣都帶；但說她兩樣都沒帶，就不對了。

## 動手玩：自己當守門員

做四張角色卡，分別畫上兩樣都有、只有鉛筆、只有橡皮擦和兩樣都沒有。請家人輪流讀出以下門牌：

1. 有鉛筆而且有橡皮擦。
2. 有鉛筆或者有橡皮擦。
3. 沒有帶橡皮擦。
4. 不是兩樣都帶。

每讀一張，你就挑出符合的角色。挑完後，不只報名字，也用一句話解釋，例如：「小米符合第三條，因為她只有鉛筆。」

## 三道小挑戰

1. 小晴帶了水壺，沒有帶帽子。她符合「有水壺而且有帽子」嗎？
2. 同樣的小晴符合「有水壺或者有帽子」嗎？
3. 阿樂說：「不是每個人都帶鉛筆，意思就是所有人都沒帶。」他把哪兩件事混在一起了？

<details class="answers" markdown="1">
<summary>查看解答與想法</summary>


1. 不符合。「而且」要求兩個條件同時成立。
2. 符合。至少一個條件成立就可以，她已經有水壺。
3. 「不是每個人都帶」只需要至少有一個人沒帶，也可能有其他人帶了。例如三人中兩人有帶、一人沒帶，就符合這句話，卻不符合「所有人都沒帶」。
