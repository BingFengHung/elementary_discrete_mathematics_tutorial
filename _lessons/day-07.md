> 今天的任務：用集合和邏輯規則分配工作，並檢查自己的理由。
> 準備：六張名字卡、紙、彩色筆。

## 新成員報到

偵探社要到校園尋寶，六位成員帶著不同裝備來集合。社長沒有直接點名誰去做什麼，而是交給你一張資料表和幾條規則。

今天不學新的大名詞。我們要把前六天的工具一起拿出來用。遇到題目時，先回頭查資料，不需要把六個人的資訊全部背在腦中。

| 成員 | 帶鉛筆 | 帶地圖 | 帶帽子 |
|---|---|---|---|
| 小安 | 是 | 是 | 否 |
| 小米 | 是 | 否 | 是 |
| 阿樂 | 否 | 是 | 是 |
| 小晴 | 是 | 是 | 是 |
| 小宇 | 否 | 否 | 是 |
| 小禾 | 是 | 否 | 否 |

今天的資料以這張表為準。活動中不交換裝備，也不臨時增加物品，讓我們能用固定資料檢查規則。

## 任務一：把資料畫成圈圈

左圈是「帶鉛筆」，右圈是「帶地圖」。請先自己在紙上畫兩個重疊的圈圈，再放進名字卡。

只帶鉛筆、沒帶地圖的是小米和小禾，放左側。只有地圖、沒帶鉛筆的是阿樂，放右側。小安和小晴兩樣都有，放中間。小宇兩樣都沒有，放兩圈外。

算一算：左側 2 人、中間 2 人、右側 1 人、外面 1 人，合計 6 人。每個人恰好放一次，才沒有漏人或增加分身。

如果問「帶鉛筆的人」，左側和中間都要算，所以是 4 人。不要把「帶鉛筆」誤讀成「只帶鉛筆」。

## 任務二：按規則選隊員

記錄隊的完整加入條件是：「帶鉛筆，而且帶地圖。」符合的是小安與小晴，因為只有他們同時滿足兩個條件。

裝備支援隊的完整加入條件是：「帶鉛筆，或者帶地圖。」數學中的或者允許兩者都有，所以除了小宇，其餘五人都符合。

現在再設一支遮陽隊：「帶帽子，而且沒有帶地圖。」先圈出帶帽子的四人：小米、阿樂、小晴、小宇。再剔除其中帶地圖的阿樂和小晴，留下小米、小宇。

這種先找一群、再檢查第二個條件的方法，能幫我們有順序地處理長一點的規則。

## 任務三：檢查有沒有倒著推

社長說：「如果加入記錄隊，就必須帶鉛筆。」

小禾立刻說：「我有鉛筆，所以我一定是記錄隊員。」這個理由夠嗎？

不夠。原來的完整加入條件還要求地圖，而小禾沒有地圖。社長那句話只說明記錄隊員一定具有的一項條件，沒有說有這一項就一定能加入。

就像 Day 5 的帶傘故事，看到結果，不能把箭頭自行反過來。

## 任務四：把模糊門牌寫清楚

原本一張門牌寫著：「帶一點裝備的人可以參加。」什麼叫一點？帽子算嗎？一定要兩樣嗎？讀的人可能有不同理解。

如果想讓所有帶鉛筆或地圖的人參加，可以改寫成：「鉛筆和地圖中，至少帶一樣就能參加；兩樣都帶也可以。」

如果只想讓帶帽子的人參加，就直接寫：「帶帽子就能參加。」寫清楚不一定要用很難的詞，而是要讓不同讀者依同一規則作出判斷。

## 動手玩：做一張任務看板

畫出三個區域，分別標示記錄隊、裝備支援隊和遮陽隊，把符合的人名寫上去。同一個人可以出現在不只一個隊伍，因為今天沒有規定一人只能參加一隊。

請家人扮演其中一位成員，問你：「我能參加哪些隊？為什麼？」你要用資料表與規則回答。

接著設計第四支隊伍，例如「帶帽子，而且帶地圖」，請對方找隊員。最後再問：如果活動另加「一人只能選一隊」，是否就需要多一個分配規則？答案是需要，因為符合資格和最後分到哪隊是兩件事。

## 三道小挑戰

1. 有幾個人「不是鉛筆、地圖兩樣都帶」？
2. 能同時加入記錄隊和遮陽隊的人有誰？
3. 小宇說：「我不在兩個圈圈裡，所以我不算偵探社成員。」他的理解哪裡出了問題？
